# GÖREV S3 — Durum makinesi simülasyonu (büyük)

**RND(a, b)** (kullanılacak sahte rastgele işlev; tüm ara değerler 64 bit tamsayı): h1 = (a*1664525 + b*1013904223 + 12345) mod 16777216; h2 = (h1*1664525 + 1013904223) mod 16777216; RND(a,b) = h2 / 16 (tamsayı bölme). `.pmt` dilinde bir alanın `alan X rastgele LO HI TOHUM` başlatıcısı, i. örnek için LO + RND(i, TOHUM) % (HI - LO + 1) değerini verir.

**Nesneler:** i = 0..20000-1 (20000 nesne), halka biçiminde dizilmiş. Nesnenin sınıfı cl(i) = RND(i,31) % 32. Her sınıfın parametreleri aşağıdaki tabloda (`c thr inf inc dur rec imm hop`).
**Durumlar:** 0 sağlam, 1 kuluçka, 2 bulaştırıcı, 3 bağışık, 4 çıkarılmış. Her nesnenin sayacı t(i) vardır.
**Başlangıç:** hepsi durum 0, t = 0; yalnız RND(i,32) % 100 < 12 olanlar durum 2 ve t = dur[cl(i)].
**Adım (s = 0..300-1)**, tüm nesneler için **eşzamanlı** (yeni durumlar yalnız önceki adımın durumlarından hesaplanır, sonra hepsi birden uygulanır). c = cl(i), h = hop[c]:
- durum 0: n = {i+1, i-1, i+h, i-h} (hepsi mod 20000) komşularından durum 2 olanların sayısı. n >= thr[c] **ve** RND(i*7919 + s, 33) % 100 < inf[c] ise yeni durum 1, t = inc[c]; değilse kalır.
- durum 1: t = t - 1; t == 0 olursa durum 2, t = dur[c].
- durum 2: t = t - 1; t == 0 olursa: RND(i*7919 + s, 34) % 100 < rec[c] ise durum 3, t = imm[c]; değilse durum 4.
- durum 3: t = t - 1; t == 0 olursa durum 0.
- durum 4: değişmez.
**Çıktı:** her kontrol adımında, yani (s + 1) % (300/4) == 0 olan adımın **sonunda** (4 kez) iki satır: (a) durum 0,1,2,3,4 olan nesne sayıları (5 sayı); (b) sınıf 0..32-1 için durum 2 olan nesnelerin sayısı (32 sayı). Toplam 8 satır.

# GÖREV U2 — Bileşen arayüzü (etkileşimli arayüz, orta)

**RND(a, b)** (kullanılacak sahte rastgele işlev; tüm ara değerler 64 bit tamsayı): h1 = (a*1664525 + b*1013904223 + 12345) mod 16777216; h2 = (h1*1664525 + 1013904223) mod 16777216; RND(a,b) = h2 / 16 (tamsayı bölme). `.pmt` dilinde bir alanın `alan X rastgele LO HI TOHUM` başlatıcısı, i. örnek için LO + RND(i, TOHUM) % (HI - LO + 1) değerini verir.

Klavye olaylarıyla yönetilen bir bileşen arayüzü. **1 pencere**, her pencerede **24 bileşen** (bileşen no i = w*24 + j; w pencere, j = 0..24-1), her pencerede **4 sütun**. Ekran 112x76 piksel, arka plan `0x101018`, **tam 150 kare**.
**Bileşen özellikleri:** tür kind(i) = RND(i,11) % 4; radyo grubu grp(i) = RND(i,12) % 3; bağımlılık: j > 0 ve RND(i,14) % 3 == 0 ise bileşen "bağımlı"dır ve bağımlı olduğu bileşen dep(i) = w*24 + RND(i,13) % j (aynı penceredeki daha küçük j'li bir bileşen); aksi hâlde bağımlı değildir. Bağımlı bileşen yalnız dep(i)'nin durumu st != 0 iken **etkindir**; bağımlı olmayanlar her zaman etkindir.
**Tür tablosu** (`k renk tip m`; renk = 0xRRGGBB onluk):
```
0 9021123 1 7
1 13840462 0 2
2 14564248 3 5
3 6850211 2 7
```
**Durum:** her bileşenin tamsayı durumu st(i), başlangıçta 0. Her pencerenin odak bileşeni fo(w) (j değeri), başlangıçta 0. Odaklı pencere wf, başlangıçta 0.
**Etkinleştirme (tip'e göre; bileşen i, tür k, m = tablodaki m):** tip 0: st = (st + 1) % m · tip 1: st = (st == 0) ? 1 : 0 · tip 2 (radyo): aynı penceredeki tip 2 türlü ve aynı grp'li **tüm** bileşenlerin st'si 0 yapılır, sonra st(i) = 1 · tip 3: st = min(st + 2, 2*m) · tip 4: st = (st == 0) ? m - 1 : 0.
**Tuşlar** (olay kodu; her karede o karede teslim edilen tüm olaylar, geliş sırasıyla, çizimden önce işlenir; w = wf, j = fo(w), i = w*24 + j):
- 1: odak bir önceki **etkin** bileşene: j - 1, j - 2, ... (mod 24, pencere içinde sarar) sırasıyla ilk etkin olan; kendisi hariç hiç etkin yoksa değişmez.
- 2: aynı biçimde sonraki etkin bileşen (j + 1, j + 2, ...).
- 3: j' = (j - 4 + 24) % 24; bileşen j' etkinse odak j' olur, değilse değişmez. 4: j' = (j + 4) % 24, aynı kural.
- 5: i etkinse etkinleştirme uygulanır.
- 6: i etkinse ve türünün tipi 0 ise st = (st + m - 1) % m; diğer durumlarda etkisiz.
- 7: wf = (wf + 1 - 1) % 1. 8: wf = (wf + 1) % 1. (9: odaklı penceredeki **tüm** bileşenlerin st'si 0 olur.) Başka her tuş yok sayılır.
**Çizim** (her karede, arka planın üstüne bu sırayla; kırpılır): pencere w'nin başlığı: dikdörtgen x = wx, y = wy - 6, genişlik 26*4 - 2, yükseklik 3, renk (w == wf) ? `0xFFC040` : `0x606060`; burada pencere başlangıcı wx = 4 + 140*(w % 4), wy = 10 + 70*(w / 4) (tamsayı bölme). Sonra **bileşenler i sırasıyla**: hücre x = wx + 26*(j % 4), y = wy + 10*(j / 4); dolu dikdörtgen (x, y, 24, 8) rengi tür tablosundaki renk — bileşen **etkin değilse** her kanal (R, G, B ayrı ayrı) 2'ye bölünmüş (tamsayı); st > 0 ise ayrıca çubuk: dikdörtgen (x + 1, y + 2, min(3*st, 22), 4) renk `0xE0E0E0`. Sonra **her pencere w için** odak işareti: dikdörtgen (x, y - 1, 24, 1) (x, y: odaklı bileşenin hücresi) renk (w == wf) ? `0xFFFFFF` : `0x808080`.
**Çıktı:** son kare sunulduktan sonra tek satır: `wf fo(0) ... fo(1-1) st(0) ... st(24-1)`.
Olaylar `ornek.girdi` gibi bir dosyadan gelir (satır: `kare tuş`); bir olay, sunulan kare sayısı olayın karesine ulaşınca teslim edilir. Doğrulama **başka olay dosyalarıyla** yapılır. Başarı ölçütü: çıktı satırı ve son karedeki her pikselin rengi.
